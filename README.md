Multi-Agent environment for the project, up-to-date environment files are the flat ones. Dependencies are in requirements.txt. Ignore IPPO and CPPO code, not used in the project. Also, ignore the dictionary-based environment setups. BenchMARL needs to be installed in the same folder from source. The basic installation involves using requirements.txt to install Python dependencies, and then installing benchMARL from source in this folder. Next in benchMARL, in the environments folder, create a new folder called myenv, and put the common.py in this GitHub here. Next, in the conf/experiment folder, update the experiment config file using the file in this GitHub. Finally, you will need to update the config YAML file in the conf folder to get things working.
